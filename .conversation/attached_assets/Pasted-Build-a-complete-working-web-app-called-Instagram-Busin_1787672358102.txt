Build a complete working web app called Instagram Business Intelligence AI Agent for Gen AI Academy APAC – Track 1: Build and Deploy a Customer-Facing AI Agent.
Goal
Create an AI marketing assistant for small businesses that analyzes uploaded Instagram analytics (CSV/JSON) and gives personalized recommendations.
Core features

* Upload Instagram analytics CSV/JSON.
* Calculate real metrics: engagement, reach, likes, comments, top/underperforming posts, trends, content-type performance.
* Interactive dashboard with charts.
* AI chat where users ask questions about their Instagram performance.
* AI generates personalized recommendations and a 7-day content plan.
* Include a Demo Data button so judges can test immediately.

AI requirements
Use:

* Google Gemini
* Google ADK
* RAG
* Tool/function calling

Create an actual ADK agent with tools such as:

* analyze_account
* analyze_content_types
* find_top_posts
* analyze_trends
* recommend_content
* generate_content_plan
* compare_periods
* search_marketing_knowledge (RAG)

The agent must choose tools based on the user's question. Do not make it a simple chatbot.
Use RAG with a small `knowledge/` folder containing Instagram marketing/content strategy information.
Never invent statistics. Recommendations must be based on the uploaded data plus RAG knowledge.
Tech stack
Frontend: React + Vite + TypeScript + Tailwind
Backend: Python + FastAPI + Google ADK + Gemini
Analytics: Pandas
RAG: FAISS or ChromaDB
Deployment: Docker + Google Cloud Run
UI
Create a polished modern SaaS dashboard:

* Overview metrics
* Performance charts
* Top posts
* AI Agent chat
* Recommendation cards showing evidence
* AI Content Planner
* CSV/JSON upload
* Demo Data mode

Show high-level agent activity such as:
`✓ Analyzed account → ✓ Retrieved marketing knowledge → ✓ Generated recommendation`
Do not expose chain-of-thought.
Important

* Do not scrape Instagram.
* Do not hard-code API keys.
* Keep Gemini credentials in `.env`.
* Include `.env.example`.
* Include sample Instagram data.
* Include Dockerfile.
* Include README with local setup and Cloud Run deployment.
* Make all buttons and features actually work; no fake placeholder UI.

Build it in a clean, modular structure and test each major feature while building it. Prioritize a working MVP over unnecessary features.
